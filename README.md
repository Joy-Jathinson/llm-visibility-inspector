# LLM Visibility Inspector

A lightweight AI search optimisation tool designed to help SEO professionals analyse website visibility and discoverability across Large Language Models (LLMs).

## What It Does

LLM Visibility Inspector helps investigate how websites and brands appear in AI-powered search experiences, supporting Generative Engine Optimisation (GEO) and Answer Engine Optimisation (AEO).

## Key Features

- Inspect website readiness for AI search visibility
- Identify potential LLM discoverability issues
- Review technical signals relevant to AI search
- Highlight opportunities for GEO improvements
- Support AI search optimisation audits

## Why I Built It

Traditional SEO tools primarily focus on search engine rankings and organic traffic. I created LLM Visibility Inspector to explore how websites can improve their discoverability in AI-powered search environments.

## Use Cases

- AI search visibility audits
- GEO and AEO analysis
- Website discoverability assessments
- Technical SEO and AI search reviews
- Identifying AI search optimisation opportunities
